# AI旅游规划助手

一个基于高德地图API的智能旅游规划Web应用，可根据用户输入自动生成个性化的旅行方案。

## 功能特性

- **智能行程规划**：根据目的地、天数、景点数自动规划每日行程
- **真实数据支持**：使用高德地图API获取真实POI和天气数据
- **路线优化**：采用贪心TSP算法优化每日景点游览顺序
- **时间调度**：自动生成游览时间表，估算交通时间和费用
- **地图导航**：生成高德地图导航链接，支持一键导航和打车
- **美食住宿推荐**：推荐当地特色美食和优质住宿
- **天气查询**：提供出行日期的天气预报
- **出行建议**：根据天气动态生成出行小贴士

## 技术栈

- **后端**: Python 3.7+ / Flask
- **前端**: HTML5 / CSS3 / JavaScript
- **API**: 高德地图 Web API
- **地图展示**: 高德地图 URI API

## 安装步骤

### 1. 克隆项目

```bash
cd travel
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 获取高德地图API Key

1. 访问 [高德开放平台](https://lbs.amap.com/)
2. 注册账号并登录
3. 进入控制台 → 应用管理 → 创建新应用
4. 添加Key，选择"Web服务"类型
5. 复制生成的Key

### 4. 启动应用

```bash
python app.py
```

应用将在 `http://localhost:5000` 启动

7. 创建地图导航链接

- 景点图片展示（3列网格布局）

- 展示图片、评分、地址
- 优先展示有图片和评分的餐厅

#### 住宿推荐
- 推荐5个优质酒店
- 展示图片、评分、地址
- 优先展示有图片和评分的酒店

#### 路线地图
- Tab切换不同天的路线
- iframe嵌入高德地图
- "查看驾车导航"按钮
- "一键打车"按钮

## 注意事项

### API Key权限

确保您的API Key具有以下权限：
- ✅ Web服务
- ✅ 地理编码
- ✅ POI搜索
- ✅ 天气查询

### 数据说明

- POI搜索半径：景点50km，美食/住宿8km
- 天气预报：最多4天，超出部分用最后一天数据补全
- 景点图片：优先使用有图片的景点，重新计算实际天数

### 性能优化

- 搜索去重：使用seen_ids集合避免重复POI
- 图片过滤：只展示有图片和评分的美食/住宿
- 路线优化：贪心TSP算法减少路程时间

## 常见问题

### Q: API Key测试失败？

A: 检查以下项：
1. Key是否正确复制（无多余空格）
2. Key是否具有Web服务权限
3. Key是否已启用
4. 账号余额是否充足

### Q: 生成的景点数量不够？

A: 可能原因：
1. 城市景点数据较少
2. API返回的POI不包含图片
3. 建议减少每天景点数或出行天数

### Q: 地图无法显示？

A: 检查：
1. 浏览器是否允许iframe
2. 网络是否正常
3. 高德地图服务是否可用

### Q: 天气数据显示异常？

A: 说明：
- 高德天气API最多返回4天预报
- 超出部分用最后一天数据补全
- 如显示null，可能是API返回异常
